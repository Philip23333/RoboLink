# 修改说明：网页控制、位姿与交互演示

日期：2026-10-20。实现提交：`543cf5e`。

## 场景一：点击前进，图标为什么会移动

选择 RB-001，以 0.2 m/s 前进 500 ms。Vue 页面生成唯一指令编号，通过 WebSocket 发送 Protobuf 二进制消息；Netty 网关检查身份、权限和参数，找到对应设备连接，再加 TCP 长度头发送。Python 模拟器先确认收到，再计算运动，到期停止并回传结果和 x=0.100 m。

页面收到遥测后更新坐标与二维箭头。按钮本身不改位置，所以断开设备、命令被拒绝时，不会出现“页面动了，机器人没执行”的假演示。TypeScript 使用共享协议类型检查字段，Vue 将最新状态显示出来，SVG 按米绘制位置与朝向，不需要复杂 3D 模型。

## 场景二：点击停止，或执行中网页断线

设备运动时再点 STOP，原运动显示“已中断”，STOP 显示“执行成功”，两条记录各有自己的编号。收到 ACK 只显示“设备已确认”，不会提前写成执行成功。

如果网页断线，未完成指令显示“结果未知”。恢复连接只重新认证和同步设备，不自动补发旧运动；旧记录也不会被迟到的消息改成成功。运动可能还在设备端继续到本地时限，网页断线不等于设备停止。结果不确定时先 STOP，再决定下一条动作。

## 场景三：遥测一直刷新，还能展开查看消息吗

同一设备的遥测在消息面板中只占最新一条，并保留展开状态，后续更新不会把详情收起来。面板展示解码后的类型、方向、设备、指令编号 / 序号和字节数，不需要人直接阅读二进制。遥测按设备合并，消息最多 120 条、指令最多 100 条，避免长时间使用时无限累积；认证内容不进入消息面板。

## 场景四：只想打开网页体验

运行 `scripts/start-demo.ps1`，本地后台启动网关、三台模拟器和网页。打开 http://127.0.0.1:5173，点击「连接本地演示」即可。首次缺少凭证时随机生成本地文件；凭证经显式启用的本地开发接口读取，不放 URL、不编译进前端产物、不保存到浏览器存储。停止入口只关闭本次监督进程启动的服务。
