# 第八步：网页位姿、控制与消息可视化

日期：2026-10-20。状态：已实现并验收，场景说明在实现提交后单独记录。

## 本次范围

- 二维网格按米绘制位置，箭头表示朝向，可选择设备、缩放和重置；没有位姿时不绘制。位置只来自遥测，点击按钮不会直接移动图标。离线或网页断连时降低图标亮度，状态文字同时说明原因。
- 前进、左转、右转、STOP，速度、角速度和时长参数受限。设备忙碌、离线、陈旧、网页断线或结果不确定时阻止新运动；STOP 可在运动中发送。
- 每条新指令用独立 UUID，发送后立即防止同设备重复运动；逐条展示发送、ACK、结果、超时、拒绝和未知。断线后未完成指令标为 UNKNOWN，不自动重发，不被迟到的成功覆盖；未知后成功 STOP 或设备新会话可解除运动限制。
- 指令记录上限 100 条，不逐出仍在处理的记录；通信消息上限 120 条，同一设备遥测仅保留最新一条，详情包含方向、类型、设备、序号 / 指令 ID、字节数及解码字段，排除认证内容。
- 加入一键启动和停止本地演示；背景进程只监听本机，随机本地凭证不进入 Git。可选 Vite 本地接口提供「连接本地演示」，拒绝跨来源 / 跨站请求；没有把 token 编译进静态包。

完整启动步骤、手动三终端方式与限制见 README。

## 限制

浏览器断开不等于机器人停止；动作依靠设备本地截止时间，设备链路故障在被检测后停止。控制结果只属于原控制会话；浏览器刷新或网关重启不会恢复历史任务订阅，超时不能作为设备未执行的证明。首次连接本地演示需用户点击按钮，手动连接方式整页刷新后需重新认证。

一键演示依赖本机 Java / Python / Node 和已准备的依赖，不包含安装系统运行时或 Docker 部署；当前仅 Windows / PowerShell 入口验证。平面软件模型不代表真实机器人安全、动力学或 SDK 接入。没有 UDP、AI、ROS2、持久化、TLS、公网部署或真实弱网并发成绩。
