# 第三步：设备注册、会话管理与心跳

状态：已实现并验收（2026-10-19），未创建 Git 提交。

## 目标

TCP 连通后，网关需要知道每个连接属于哪台设备，并维护当前有效连接。本步建立可启动的设备接入服务，使用本地配置的开发凭证完成认证，管理连接替换、遥测状态和存活期限。

## 已完成范围

- [x] 只允许未注册连接先发送 Register；成功后返回新会话编号和心跳参数。
- [x] 按设备配置独立凭证；错误凭证、未知设备和不合法设备 ID 被拒绝。
- [x] 注册成功前校验版本、消息类型、设备 ID、凭证及空 session_id。
- [x] 在线索引记录当前连接、会话编号、最后活跃时间和最新遥测。
- [x] 相同设备新连接通过认证后替换旧连接，旧连接关闭不会删掉新会话。
- [x] 已注册消息必须匹配 robot_id / session_id，并采用会话内递增序号。
- [x] 正确心跳返回确认；合法遥测更新最新状态，重复或过期序号不更新存活时间。
- [x] 注册等待和注册后的合法消息空闲超时分别处理，半条消息不能延长等待期限。
- [x] 主动断线、协议错误、心跳超时和服务关闭均清理在线会话及定时任务。
- [x] Java 主程序与本机默认启动入口可用，Python 客户端可实际注册和发送心跳。

## 执行与验收入口

```powershell
.\scripts\verify-session.ps1 -Clean
.\scripts\verify-protocol.ps1
.\.venv\Scripts\python.exe .\scripts\smoke-gateway.py
```

按顺序在同一 PowerShell 终端执行。第一条准备 Java 环境并验证本步；第二条同时回归前两步并生成 Python 协议、准备运行依赖；第三条临时启动真实 Java 主程序，再用 Python 做 TCP 验证，结束后清理测试进程和临时凭证。

本步新增 31 项 JUnit 测试，前一步 23 项仍全部通过，共 54 项；三端序列化互通的 18 次消息比较也通过。

## 启动与范围

启动方式见 README 的“启动设备 TCP 网关”。默认监听 `127.0.0.1:9000`，注册期限 5 秒，建议设备每 3 秒心跳，连续 10 秒没有合法消息则关闭连接。文件中的凭证只在启动时读取。

当前已注册设备可以发送 Heartbeat 和 Telemetry，指令 ACK / Result 路由将在下一步加入。在线索引是内存状态，退出后不保存设备历史，也没有 HTTP 或网页查询入口。

实现入口为 `GatewayServer`、`DeviceConnectionPipeline` 和 `SessionRegistry`；详细结果见 `docs/acceptance-step-03.md`，通俗说明见 `docs/changes/003-设备注册会话与心跳.md`。
