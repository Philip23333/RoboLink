# 第七步：Vue 设备订阅与实时监控

日期：2026-10-20。状态：已实现并验收。

Vue3 + TypeScript + Vite 页面已接入正式 WebSocket 二进制接口。账号凭证经第一条 Protobuf 消息认证，不进入 URL；认证后订阅设备，先取快照再处理实时遥测与上下线通知。凭证仅保留当前页面内存，输入框提交后清空，不写浏览器存储；整页刷新后需重新认证，连接临时中断会自动重新认证并同步。

按设备 ID 和 session_id 保存最新状态，64 位序号使用 bigint 比较；旧会话和重复序号被丢弃，新会话可以从小序号重新开始。网页断线、设备离线与超过 3 秒未更新分别显示。收到的遥测速率口径为最近 5 个一秒桶的条数除以 5，不代表网关总吞吐或性能上限。

遥测最多每 100 ms 通知页面更新一次，状态按设备覆盖；连接维护每 500 ms 更新陈旧状态。连接超时 7 秒，重连采用带抖动、最大 5 秒的退避。接到无效消息停止本次连接并提示，不显示伪造在线状态。

## 启动

先启动网关和模拟器，再在第三个终端执行：

```powershell
cd console
npm ci
npm run dev
```

打开 http://127.0.0.1:5173，账号默认 operator，输入 `controllers.local.properties` 中相应本地凭证后连接。页面不提供固定凭证。开发端口必须为 5173，或同时修改网关 Origin 许可。

## 验收

```powershell
# 首次安装浏览器
cd console
npx playwright install chromium
cd ..
.\scripts\verify-console.ps1
```

4 项状态测试、Vue 类型检查和生产构建通过；4 项真实 Chromium 测试通过：二进制订阅与三设备展示、选择与刷新后快照、错误凭证和存储检查、设备离线及网关重启恢复、手机宽度无溢出。部分行为组合在同一测试内，不叠加计算用例数。

测试临时启动真实网关、设备和页面，使用 19000 / 19001 / 19005 测试端口和 5173 页面端口；固定凭证仅用于隔离测试环境，不属于开发网关配置。测试管理接口只用于本机自动化，拒绝带 Origin 的浏览器请求，不是产品接口。

证据：[浏览器报告](evidence/step-07-browser-report.json)，截图在 `artifacts/browser/step-07-monitor.png` 和 `step-07-mobile.png`。已人工查看桌面截图。无真实硬件或性能上限结论。
