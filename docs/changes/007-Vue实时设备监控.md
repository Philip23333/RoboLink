# 修改说明：Vue 实时设备监控

日期：2026-10-20。实现提交：`a9799aa`。

## 场景一：打开网页，看见真实回传的三台设备

网页输入本地账号凭证，WebSocket 建立双向连接，第一条 Protobuf 消息完成认证；网关随后给出设备快照，再持续推送电量、位姿和状态。Vue 负责把状态变化显示出来，TypeScript 负责在开发时检查消息结构，Vite 负责本地运行和构建页面。页面没有预填设备数量或吞吐成绩，未连接时显示等待。

## 场景二：设备离线，与网页断线有什么区别

RB-003 离线时，另外两台仍更新，网页显示 RB-003 离线；网页自身失去网关连接时，所有设备状态变为连接中断，不能继续把旧快照当作在线证据。连接恢复后重新认证和订阅，更新整份快照，而不是简单把旧设备改回在线。

## 场景三：重连后序号又从 1 开始

页面先比较会话编号，再比较会话内序号。新会话的第 1 条可以接受，旧会话迟到的第 100 条不能覆盖它。序号使用 bigint，避免 JavaScript 普通数字的大整数精度问题。

遥测按设备保留最新状态，最多每 100 ms 通知页面更新一次；没有把每条遥测无限追加到界面。凭证只在当前页面内存中，输入后清空，不写本地存储；整页刷新需要重新输入凭证。
