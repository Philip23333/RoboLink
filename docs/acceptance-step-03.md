## 结果

| 验证内容 | 结果 |
| --- | --- |
| 注册与凭证 | 有效设备成功；错误凭证、未知 ID、非法 ID、冒用其他设备凭证、携带旧会话编号均被拒绝 |
| 注册流程约束 | 注册前遥测、同一连接重复注册被拒绝；注册凭证不向后转发 |
| 注册期限 | 不完整消息无法延长绝对期限；成功注册后原注册期限被取消 |
| 身份绑定 | 后续 robot_id / session_id 必须匹配当前连接；设备不能发送仅供服务端使用的消息 |
| 遥测与序号 | 最新位置被保存；心跳保留原遥测；重复和过期序号不更新快照；按无符号 64 位比较序号 |
| 非法遥测 | 非有限坐标在进入状态缓存前被拒绝 |
| 替换竞态 | 故意延迟旧连接关闭；旧数据不能写入新会话，旧清理不能删除新会话 |
| 真实 TCP 替换 | 新连接注册后旧连接收到 EOF，新连接仍可完成心跳确认 |
| 空闲处理 | 真实连接不再发送合法消息后超时；持续合法心跳可跨过空闲期限维持在线 |
| 断线与异常 | 主动断线、编解码错误均移除会话；服务关闭同时处理已注册和未注册连接 |
| 启动失败 | 端口绑定失败会清理服务器资源，该失败实例不可重新启动 |

新增测试为 **22 项设备会话测试 + 9 项真实服务生命周期测试 = 31 项**，失败、错误、跳过均为 0。连同第二步 23 项测试，总计 **54 项**，全部通过。

## 真实 Java 主程序与 Python 联调

联调脚本创建临时随机凭证文件，启动真正的 `GatewayMain`，仅绑定本机随机端口。Python 完成注册、发送遥测与心跳，核对返回会话及确认序号；身份不匹配时连接收到 EOF，错误凭证被拒绝。

结束后测试 Java 进程退出，临时凭证文件删除，不把凭证写入报告。该探针通过终止自己的测试进程完成收尾；优雅关闭的资源清理另由 JUnit 的服务器关闭测试验证，不将两者混为同一种证据。
