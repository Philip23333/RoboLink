## 验证项目

| 项目 | 验证方式 |
| --- | --- |
| 通信闭环 | 真实 JDK WebSocket 客户端发指令，Netty 转到指定 TCP 测试设备，设备回 ACK / Result，原客户端收到终态 |
| 路由隔离 | 另一台设备没有收到该指令，另一控制客户端的消息记录中没有该指令的 ACK、结果或状态 |
| 订阅与权限 | 指定设备范围、离线快照、遥测转发、上下线通知、越权拒绝 |
| 身份入口 | 控制凭证文件加载，错误凭证、未认证消息、非法 Origin、缺少 Origin、URL 查询参数被拒绝 |
| 连接期限 | HTTP 握手只发一部分时超时；WebSocket 升级后不认证也超时 |
| 消息边界 | 分片二进制认证成功；分片合计超出 64 KiB、文本、损坏 Protobuf、错误版本关闭连接 |
| 状态机 | 接受、拒绝、执行失败、中断、ACK 超时、结果超时、结果早于 ACK、迟到回包不重开终态 |
| 参数与设备状态 | 非有限值、超限速度、非法持续时间、无效动作、离线、忙碌、已知非空闲状态拒绝；STOP 可优先发送 |
| 路由后大小 | 客户端消息本身未超限，但补设备会话后会超过 64 KiB 时拒绝指令，保留设备连接 |
| 会话变化 | 设备换连接后旧指令 UNKNOWN，不重发到新连接；控制端断线后结果不转交新客户端 |
| 短期去重 | 相同 ID 与参数返回已有状态；冲突 ID 拒绝；容量满不逐出未过期记录；到期释放容量 |
| 不确定执行 | 超时后新运动被阻止；仍能发送 STOP，收到成功结果后可解除对应不确定状态 |
| 慢消费者 | 100 次遥测合并成最后一条；可靠队列超限断开；单次输出持续不完成时断开 |

## 边界

测试设备只按测试步骤回报状态，没有真正执行运动。尚无 Vue 控制台、完整 Python 多机器人模拟器、UDP、实体机器人或持久化。

状态记录只在本进程的保留窗口内有效，控制会话断开后不支持恢复历史任务订阅。ACK 超时包含本地排队时间，结果超时从接受 ACK 开始。超时和发送异常不证明设备没有执行，网关不自动重试运动，也不宣称已远程停止。

这是单实例、单协调线程的开发网关。默认仅本机监听，未部署 TLS，没有真实弱网或并发压测数据。
